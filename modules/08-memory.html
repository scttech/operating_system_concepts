Module 8

Memory Management

Programs must be in memory to run. The OS decides where, keeps processes out of each other's memory, and makes limited RAM feel large and private.

Logical vs. physical addresses

The CPU generates logical (virtual) addresses. The MMU translates each one into a physical address at run time. That indirection lets the OS relocate programs, enforce protection and share memory without the program noticing.

Contiguous allocation

The simplest scheme gives each process one contiguous block. When a request arrives, the OS must pick a free hole:

  • First-fit: first hole that is big enough (fast).
  • Best-fit: smallest hole that fits (leaves tiny leftover slivers).
  • Worst-fit: largest hole (leaves big leftovers, but destroys large holes).

Over time, free memory shatters into many small holes: external fragmentation. Compaction fixes it by sliding processes together, at the cost of copying and relocating them.

Paging

Paging splits the logical address space into fixed-size pages and physical memory into same-size frames. A page table maps each page to a frame, so a process's memory need not be contiguous. This removes external fragmentation; the cost is internal fragmentation in each process's last page (about half a page on average).

A logical address splits into two parts: page number (high bits, index into the page table) and offset (low bits, position inside the page). For a page size of 2n bytes, the offset is n bits. For example, a 32-bit address with 4 KiB pages has a 20-bit page number and 12-bit offset.

Making translation fast

A page table lives in memory, so each access would need two memory references. The TLB caches recent translations in hardware. With TLB hit ratio h:

EAT = h × (tTLB + tmem) + (1 − h) × (tTLB + 2 × tmem)

With a 1 ns TLB, 100 ns memory and a 98% hit ratio: EAT = 0.98 × 101 + 0.02 × 201 = 103 ns, only 3% slower than raw memory.

Large address spaces

  • Hierarchical (multi-level) page tables only allocate the parts of the table that are in use.
  • Hashed and inverted page tables trade lookup time for table size.
  • Segmentation divides memory by logical units (code, stack, heap). Modern systems mostly use paging, sometimes with segment-like protection.
  • Protection bits in each page-table entry (valid, read/write, execute, user/supervisor) let the MMU enforce isolation.
