Calculation Practice

A fresh problem every time, checked instantly, with a step-by-step worked solution. These are the calculations that appear on exams: scheduling, page replacement, disk scheduling, address translation and more.

How this works
  • Every problem comes from a problem code (for example disk:48213:2). The same code always gives the same problem, so you can send a link to a classmate or use one in an assignment.
  • Warm-up problems use fewer and smaller numbers. Exam-style problems add more processes, more algorithms and trickier cases.
  • Try it yourself first. A wrong answer does not reveal the solution, and “Show solution steps” does. Problems you solve on the first try count toward your score for this visit (nothing is saved).
  • Conventions are stated in each problem, for example how ties are broken and whether the return trip of C-SCAN counts. Different textbooks sometimes differ, so use the rules given here.
