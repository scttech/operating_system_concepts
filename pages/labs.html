Hands-on practice

Python Labs

Short, runnable experiments that make operating-system ideas visible. Each lab has a script you run on your own computer, a guided tour of what to notice, experiments to try, and questions to reflect on.

Also optional: Hands-on with Docker. A separate set of labs that uses Docker to explore operating-system ideas on a real kernel: shared kernels, namespaces and resource limits. It needs Docker installed, and nothing else on this site depends on it.

The labs

    How the labs work

    1. Read the lesson first (each lab links to its related modules). The simulations on those pages show the idea; the labs show the real thing.
    2. Predict, then run. Before running a script, write down what you expect to see. The learning is in the gap between prediction and result.
    3. Change one thing at a time in the “Try it” section and explain what changed.
    4. Answer the reflection questions in your own words (they work well as journal entries).

    Why not run Python inside this page? Browsers cannot run os.fork, real threads with locks, or system tools like psutil the way a real computer does, and those are exactly the things these labs explore. Running the scripts yourself also means you see your own machine's behavior.

    Every script on these pages is a real file you can download and run. They have been tested on Windows and on Linux, and the sample output you see is from real runs.
