Lab 4

Semaphores and deadlock prevention

Coordinate producers and consumers with semaphores so a bounded buffer never overflows or underflows. Then build the classic dining-philosophers deadlock, detect it, and prevent it by breaking one of the four deadlock conditions.

About 50 minutesAny systemRelated: Module 6 Synchronization, Module 7 Deadlocks

What you will practice

  • Using semaphores as counters of free and filled slots.
  • Combining a semaphore-based protocol with a mutex that protects the buffer.
  • Creating a deadlock on purpose and recognizing its symptoms.
  • Preventing it by removing circular wait with a resource ordering.

The script

One script has two parts: the bounded buffer (producers and consumers), then the dining philosophers. Predict first: in Part B all five philosophers pick up their left fork first. What do you expect to happen?

Python's threading.Semaphore, threading.Barrier and acquire(timeout=...) are built in, which is why this version is much shorter. Use it to focus on the protocol: which semaphore to wait on, in what order.

"""Lab 4 - Semaphores, the bounded buffer, and preventing deadlock."""
import collections
import threading
import time

# ---------- Part A: bounded buffer (producers and consumers) ----------
BUFFER_SIZE, PRODUCERS, CONSUMERS, ITEMS_EACH = 3, 2, 2, 6
buffer = collections.deque()
empty = threading.Semaphore(BUFFER_SIZE)    # (1) counts FREE slots; starts at the buffer size
full = threading.Semaphore(0)               # (2) counts FILLED slots; starts at zero
mutex = threading.Lock()                    # (3) protects the deque itself
consumed = []
peak = 0


def producer(pid):
    global peak
    for i in range(ITEMS_EACH):
        empty.acquire()                     # wait(empty): block if the buffer is full
        with mutex:
            buffer.append((pid, i))
            peak = max(peak, len(buffer))
        full.release()                      # signal(full): one more item is available


def consumer(count):
    for _ in range(count):
        full.acquire()                      # wait(full): block if the buffer is empty
        with mutex:
            consumed.append(buffer.popleft())
        empty.release()                     # signal(empty): one more free slot


threads = [threading.Thread(target=producer, args=(p,)) for p in range(PRODUCERS)]
threads += [threading.Thread(target=consumer, args=(PRODUCERS * ITEMS_EACH // CONSUMERS,)) for _ in range(CONSUMERS)]
for t in threads:
    t.start()
for t in threads:
    t.join()
in_order = all([i for p, i in consumed if p == who] == list(range(ITEMS_EACH)) for who in range(PRODUCERS))
print(f"bounded buffer: produced {PRODUCERS * ITEMS_EACH}, consumed {len(consumed)}, "
      f"largest buffer size seen {peak} (limit {BUFFER_SIZE}), each producer's items stayed in order: {in_order}")

# ---------- Part B: dining philosophers ----------
N, MEALS, PATIENCE = 5, 3, 2.0


def dinner(name, pick_order):
    forks = [threading.Lock() for _ in range(N)]
    sit_down = threading.Barrier(N)
    abort = threading.Event()
    meals = [0] * N

    def philosopher(i):
        first, second = pick_order(i, (i + 1) % N)          # which fork to pick up first
        sit_down.wait()                                     # everyone starts at the same moment
        for _ in range(MEALS):
            forks[first].acquire()
            time.sleep(0.05)                                # (4) think while holding one fork: this makes deadlock likely
            while not forks[second].acquire(timeout=0.05):  # (5) wait for the second fork, but keep checking for the alarm
                if abort.is_set():
                    forks[first].release()
                    return
            meals[i] += 1                                   # eat
            forks[second].release()
            forks[first].release()

    people = [threading.Thread(target=philosopher, args=(i,), daemon=True) for i in range(N)]
    for p in people:
        p.start()
    deadline = time.time() + PATIENCE
    for p in people:
        p.join(timeout=max(0.0, deadline - time.time()))
    stuck = sum(p.is_alive() for p in people)
    if stuck:
        print(f"{name}: DEADLOCK after {PATIENCE:.0f} s: {stuck} of {N} philosophers stuck, meals eaten {sum(meals)} of {N * MEALS}")
        abort.set()                                         # sound the alarm so the program can end
        for p in people:
            p.join()
    else:
        print(f"{name}: all {N} philosophers finished, {sum(meals)} meals eaten, no deadlock")


dinner("naive (left fork first)", lambda left, right: (left, right))
dinner("ordered (lower-numbered fork first)", lambda left, right: (min(left, right), max(left, right)))

C needs more code, and the extra code is the lesson. There is no counting semaphore that works everywhere (POSIX unnamed semaphores are missing on macOS), so this version builds one from a mutex and a condition variable. That is how semaphores are actually implemented: semaphore_wait sleeps on the condition variable until the count is positive, and semaphore_signal increments it and wakes a sleeper. try_lock_for polls because there is no portable timed lock. Build it with gcc -std=c99 -D_POSIX_C_SOURCE=200809L -pthread -o lab4_sync lab4_sync.c. It prints the same lines as the Python version (the bounded buffer's “largest size seen” can be 1, 2 or 3).

/* Lab 4 (C) - Semaphores, the bounded buffer, and preventing deadlock. Build with:  gcc -std=c99 -D_POSIX_C_SOURCE=200809L -pthread */
#include <pthread.h>
#include <stdio.h>
#include <time.h>

static void pause_ms(int ms) { struct timespec t = { ms / 1000, (ms % 1000) * 1000000L }; nanosleep(&t, NULL); }

/* A counting semaphore built from a mutex and a condition variable. (POSIX has semaphores too, but macOS lacks
   the unnamed kind, and building one shows what wait() and signal() really do.) */
typedef struct { pthread_mutex_t m; pthread_cond_t c; int value; } semaphore;
static void semaphore_init(semaphore *s, int value) { pthread_mutex_init(&s->m, NULL); pthread_cond_init(&s->c, NULL); s->value = value; }
static void semaphore_wait(semaphore *s) {                       /* wait / P / acquire */
    pthread_mutex_lock(&s->m);
    while (s->value <= 0) pthread_cond_wait(&s->c, &s->m);       /* sleep until another thread signals */
    s->value--;
    pthread_mutex_unlock(&s->m);
}
static void semaphore_signal(semaphore *s) {                     /* signal / V / release */
    pthread_mutex_lock(&s->m);
    s->value++;
    pthread_cond_signal(&s->c);
    pthread_mutex_unlock(&s->m);
}

/* ---------- Part A: bounded buffer (producers and consumers) ---------- */
#define BUFFER_SIZE 3
#define PRODUCERS 2
#define CONSUMERS 2
#define ITEMS_EACH 6
typedef struct { int producer, index; } item;
static item buffer[BUFFER_SIZE], consumed[PRODUCERS * ITEMS_EACH];
static int head = 0, count = 0, peak = 0, n_consumed = 0;
static semaphore empty_slots, full_slots;                        /* (1) free slots start at the buffer size; (2) filled slots at zero */
static pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;        /* (3) protects the buffer itself */

static void *producer(void *arg) {
    int pid = (int)(long)arg;
    for (int i = 0; i < ITEMS_EACH; i++) {
        semaphore_wait(&empty_slots);                            /* wait(empty): block if the buffer is full */
        pthread_mutex_lock(&mutex);
        buffer[(head + count) % BUFFER_SIZE] = (item){ pid, i };
        count++;
        if (count > peak) peak = count;
        pthread_mutex_unlock(&mutex);
        semaphore_signal(&full_slots);                           /* signal(full): one more item is available */
    }
    return NULL;
}

static void *consumer(void *arg) {
    int take = (int)(long)arg;
    for (int k = 0; k < take; k++) {
        semaphore_wait(&full_slots);                             /* wait(full): block if the buffer is empty */
        pthread_mutex_lock(&mutex);
        consumed[n_consumed++] = buffer[head];
        head = (head + 1) % BUFFER_SIZE;
        count--;
        pthread_mutex_unlock(&mutex);
        semaphore_signal(&empty_slots);                          /* signal(empty): one more free slot */
    }
    return NULL;
}

static void bounded_buffer(void) {
    pthread_t t[PRODUCERS + CONSUMERS];
    semaphore_init(&empty_slots, BUFFER_SIZE);
    semaphore_init(&full_slots, 0);
    for (long p = 0; p < PRODUCERS; p++) pthread_create(&t[p], NULL, producer, (void *)p);
    for (long c = 0; c < CONSUMERS; c++) pthread_create(&t[PRODUCERS + c], NULL, consumer, (void *)(long)(PRODUCERS * ITEMS_EACH / CONSUMERS));
    for (int i = 0; i < PRODUCERS + CONSUMERS; i++) pthread_join(t[i], NULL);
    int in_order = 1;
    for (int who = 0; who < PRODUCERS; who++) {
        int next = 0;
        for (int k = 0; k < n_consumed; k++) if (consumed[k].producer == who && consumed[k].index != next++) in_order = 0;
    }
    printf("bounded buffer: produced %d, consumed %d, largest buffer size seen %d (limit %d), each producer's items stayed in order: %s\n",
           PRODUCERS * ITEMS_EACH, n_consumed, peak, BUFFER_SIZE, in_order ? "True" : "False");
}

/* ---------- Part B: dining philosophers ---------- */
#define N 5
#define MEALS 3
#define PATIENCE_MS 2000

typedef void (*pick_order_fn)(int left, int right, int *first, int *second);
static void naive(int left, int right, int *first, int *second) { *first = left; *second = right; }
static void ordered(int left, int right, int *first, int *second) { *first = left < right ? left : right; *second = left < right ? right : left; }

static pthread_mutex_t forks[N], state = PTHREAD_MUTEX_INITIALIZER;
static pthread_cond_t all_seated = PTHREAD_COND_INITIALIZER;
static int seated, meals[N], done[N], alarm_on;
static pick_order_fn pick_order;

static int try_lock_for(pthread_mutex_t *m, int ms) {            /* like Python's acquire(timeout=...): poll until the time is up */
    for (int waited = 0; waited < ms; waited++) { if (pthread_mutex_trylock(m) == 0) return 1; pause_ms(1); }
    return 0;
}

static void *philosopher(void *arg) {
    int i = (int)(long)arg, first, second;
    pick_order(i, (i + 1) % N, &first, &second);                 /* which fork to pick up first */
    pthread_mutex_lock(&state);                                  /* everyone starts at the same moment (a simple barrier) */
    if (++seated == N) pthread_cond_broadcast(&all_seated);
    while (seated < N) pthread_cond_wait(&all_seated, &state);
    pthread_mutex_unlock(&state);
    for (int m = 0; m < MEALS; m++) {
        pthread_mutex_lock(&forks[first]);
        pause_ms(50);                                            /* (4) think while holding one fork: this makes deadlock likely */
        while (!try_lock_for(&forks[second], 50)) {              /* (5) wait for the second fork, but keep checking for the alarm */
            pthread_mutex_lock(&state); int stop = alarm_on; pthread_mutex_unlock(&state);
            if (stop) { pthread_mutex_unlock(&forks[first]); return NULL; }
        }
        pthread_mutex_lock(&state); meals[i]++; pthread_mutex_unlock(&state);                 /* eat */
        pthread_mutex_unlock(&forks[second]);
        pthread_mutex_unlock(&forks[first]);
    }
    pthread_mutex_lock(&state); done[i] = 1; pthread_mutex_unlock(&state);
    return NULL;
}

static void dinner(const char *name, pick_order_fn order) {
    pthread_t t[N];
    pick_order = order; seated = 0; alarm_on = 0;
    for (int i = 0; i < N; i++) { pthread_mutex_init(&forks[i], NULL); meals[i] = 0; done[i] = 0; }
    for (long i = 0; i < N; i++) pthread_create(&t[i], NULL, philosopher, (void *)i);
    int finished = 0;
    for (int waited = 0; waited < PATIENCE_MS && finished < N; waited += 10) {
        pause_ms(10);
        pthread_mutex_lock(&state);
        finished = 0; for (int i = 0; i < N; i++) finished += done[i];
        pthread_mutex_unlock(&state);
    }
    int total = 0;
    pthread_mutex_lock(&state); for (int i = 0; i < N; i++) total += meals[i]; pthread_mutex_unlock(&state);
    if (finished < N) {
        printf("%s: DEADLOCK after %d s: %d of %d philosophers stuck, meals eaten %d of %d\n", name, PATIENCE_MS / 1000, N - finished, N, total, N * MEALS);
        pthread_mutex_lock(&state); alarm_on = 1; pthread_mutex_unlock(&state);   /* sound the alarm so the program can end */
    } else {
        printf("%s: all %d philosophers finished, %d meals eaten, no deadlock\n", name, N, total);
    }
    for (int i = 0; i < N; i++) pthread_join(t[i], NULL);
}

int main(void) {
    bounded_buffer();
    dinner("naive (left fork first)", naive);
    dinner("ordered (lower-numbered fork first)", ordered);
    return 0;
}

Part A: what to notice (bounded buffer)

  1. (1) empty counts free slots and starts at the buffer size. A producer must acquire (wait on) it before adding an item, so it blocks when the buffer is full.
  2. (2) full counts filled slots and starts at 0. A consumer must acquire it before removing an item, so it blocks when the buffer is empty.
  3. (3) mutex is a separate lock that protects the deque itself. The semaphores decide when a thread may proceed; the mutex makes the actual insert or remove safe.
  4. These are exactly the empty = N, full = 0, mutex = 1 initial values from the lesson. acquire() is wait() (P) and release() is signal() (V).
  5. The “largest buffer size seen” can never exceed the limit. That is the guarantee the empty semaphore provides.

Part B: what to notice (dining philosophers)

  1. (4) Holding one fork while waiting for the second (hold and wait) is what makes deadlock possible. The short sleep makes sure every philosopher is holding a fork before anyone tries for the second one, so the deadlock happens every time.
  2. All four deadlock conditions are present in the naive version: forks are exclusive (mutual exclusion), each philosopher holds one and waits for another (hold and wait), forks cannot be taken away (no preemption), and philosopher 0 waits for 1 waits for 2 … waits for 4 waits for 0 (circular wait). See the four conditions.
  3. (5) Detecting the deadlock. The program cannot know a deadlock exists. It only sees that nobody has finished after two seconds. Real systems use timeouts and watchdogs the same way, then recover (here by sounding an alarm so the threads give up).
  4. The fix: if every philosopher picks up the lower-numbered fork first, philosopher 4 reaches for fork 0 before fork 4. A cycle of waiting can no longer form (circular wait is impossible), so at least one philosopher can always eat. Try the dining-philosophers simulator to see the same two strategies.

Try it

  1. Make the bounded buffer deadlock. In producer, swap the order so it takes mutex before empty.acquire(). Run it with a small buffer. What happens, and why? (The lesson warns about exactly this.)
  2. Try a different fix. Add a third strategy: a Semaphore(N - 1) “waiter” that only lets four philosophers sit at once. Which deadlock condition does that break?
  3. Change PATIENCE to 0.5. Does the naive version still report a deadlock? What if it is too short for the ordered version to finish?
  4. Change BUFFER_SIZE to 1 and then 10. Does the “largest size seen” follow it?
  5. Give each philosopher a random thinking time with random.uniform. Is the naive version still deadlocked every time? What does that tell you about intermittent deadlocks in real programs?

Common mistakes

  • Acquiring in the wrong order. Taking the mutex before the semaphore can block everyone while holding the lock.
  • Forgetting to release (especially when an exception happens). Use with lock: so release is automatic.
  • Releasing a semaphore too many times silently raises its count. threading.BoundedSemaphore raises an error instead, which helps catch the bug.
  • Joining threads without a timeout. A deadlocked program just hangs and gives you no clue. Timeouts turn a hang into a message.

Reflection questions (good journal entries)

  1. Why are two kinds of synchronization (semaphores and a mutex) needed in the bounded buffer? What could go wrong with only the semaphores?
  2. The deadlock was easy to cause here and might be rare in a real program. Why do intermittent deadlocks make better evidence of a design flaw than a one-off hang?
  3. Compare prevention (ordering the forks) with avoidance (the Banker's algorithm). Which would you choose for this problem and why?
